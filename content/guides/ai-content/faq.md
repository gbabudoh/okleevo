title: AI Content FAQ
summary: Common questions and troubleshooting for AI Content.
---

## Is my generated content saved anywhere?

No — generation history only lives in your browser tab for the current session. Copy or download anything you want to keep before navigating away or refreshing.

## Which AI model writes the content?

Generation is powered by Groq by default, with an automatic fallback to Gemini if Groq isn't available — you don't need to choose a provider yourself.

## Why does the Generate button work even if I've only filled in one field?

The button only requires at least one field to have a value, so you can experiment with partial input — though filling in more fields (tone, audience, keywords) generally produces a more useful result.

## What does "Generation failed" mean?

It means neither AI provider was able to return a result for that request — usually a temporary issue. Try generating again.

## Can I edit the generated text before saving it?

Not inside AI Content itself — copy the text into your usual editor (or your document/email tool) to refine it further.

## Can I rewrite or improve text I already have, rather than generate something new?

Not from this page currently — AI Content is generate-only. A separate writing-assist tool for improving existing text exists elsewhere in Okleevo (on the Helpdesk module).
