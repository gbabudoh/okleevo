## Tutorial: Running a task from creation to done

1. Click **New Task**, give it a title, set a priority and due date, and assign it to someone.
2. As work starts, quick-move the card from **To Do** to **In Progress** using the arrow button.
3. Break the work into a checklist by opening the task and adding subtasks — tick them off as they're completed.
4. When everything is finished, open the task and click **Mark as Done**.

## Tutorial: Reviewing a busy column

1. Switch a crowded column to a cleaner order using its "⋯" menu → **Sort by Priority**, so Urgent items float to the top.
2. Once you've cleared out finished work, use **Clear Completed** on that column to tidy the board for the session.

## Tutorial: Tracking work tied to a project's invoice

If a task is linked to a Project, keep in mind that Okleevo automatically pauses that project's open tasks if its invoice becomes overdue — the assigned person gets a notification. If a task you expect to see has quietly disappeared from the board, check whether its linked project has an overdue invoice.

## Tutorial: Finding a specific task quickly

1. Type a keyword from the title or description into the search box.
2. Narrow further with the Status or Priority filter.
3. If you're looking for your own work, use the Assignee filter (visible once tasks have been assigned).
