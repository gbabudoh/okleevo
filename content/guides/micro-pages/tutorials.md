## Tutorial: Building a product launch page

1. Click **Create New**, choose the **Marketing** category, and pick the **Product Launch** template.
2. In the editor that opens, update the Page Title and Slug to match your product.
3. Fill in the Meta Title and Meta Description so the page is ready for search engines.
4. Review the pre-filled sections (Hero, Features, CTA, Footer) and click **Save & Deploy** when you're happy.

## Tutorial: Setting up a "coming soon" page

1. Choose the **Coming Soon** template from the Marketing category.
2. Edit the title and SEO fields, then save.
3. Use **Copy URL** from the page's "⋮" menu to grab the link for sharing once the module supports live publishing.

## Tutorial: Comparing templates before committing

1. Open the template picker and switch between category tabs (Marketing, Events, Sales, Personal) to see what's available.
2. Create a page from a template you like — you can always edit the title, slug, and sections afterward, so it's fine to start and refine.
