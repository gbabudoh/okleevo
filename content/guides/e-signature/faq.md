title: E-Signature FAQ
summary: Common questions about the E-Signature preview.
---

## Are documents I upload actually stored?

Not yet — this module is an early preview, so uploads, signatures, and status changes only exist while you're on the page and disappear on refresh.

## Is a signature made here legally binding?

Not currently — since nothing is saved or sent to a recipient yet, don't rely on this for real contracts or legally binding agreements.

## Can I send a document to someone else to sign?

Not yet — there's no real recipient or delivery workflow in the current preview.

## Why did my uploaded document disappear when I refreshed the page?

Because nothing in this module is saved between visits yet — this is expected in the current preview.

## Will my signed documents be available later once this is fully built out?

Not from anything created in the current preview — check back as the module develops for persistent document storage and real recipient workflows.
